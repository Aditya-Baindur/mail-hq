# Historical delivery test

An owner-authorized test used 20 messages to one Gmail account and its plus aliases. All 20 were accepted by the recipient mail server; one had a temporary rate-related deferral before acceptance. Initial folder placement was not independently measured.

This does not establish an inbox-placement success rate. Plus aliases share one inbox, and mail-server acceptance is different from placement in Inbox or Spam.

Private recipient addresses, message IDs, provider logs, and credentials are excluded from the public repository. The original operator report is retained locally. No further test batch is scheduled or implied by deploying this project.
